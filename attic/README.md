# attic/ — 退避(削除でなく凍結保管)

ここは**現役契約から外した、消費者ゼロのコード**を削除せず退避する場所である
(simplicity 計画 R-08 と同じ方式)。検証の床(ruff / pyright)からは除外される。

## api_response_v1.py / errors_v1.py(L-4 で退避)

**例外 raise 型のレスポンス族。** SuccessCode / ErrorCode Enum をフォーマット族
(`web/http_response_formatter.py` 系=現役契約)と二重定義しており、消費者はゼロ
(唯一の消費未遂は F-1 の壊れた import で、Q-3 でフォーマット族へ寄せて解消済み)。

フォーマット族(現役契約)との**統合判断は v2 設計時に行う**。それまでは現役の
検証・契約から切り離してここに保管する。復活させる場合は現役契約との重複解消が前提。
